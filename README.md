# ListadeTarefas
Sistema de Aplicativo de Tarefas simples para uma atividade de Fundamentos de Eng. de Software. do curso de bacharelado em sistemas da informação. 

# Nome do Sistema
To do List é o nome do sistema.

# Objetivo do Sistema
O objetivo do sistema é possibilitar anotar lista de afazeres como se fossem post its para organizar melhor o dia.

#Principais Funcionalidades
A principal função é fazer anotações e marcar como concluído ou não, apagar, editar e fazer novas anotações.
